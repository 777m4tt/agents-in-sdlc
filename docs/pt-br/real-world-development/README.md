Explore o GitHub Copilot ao longo do ciclo de vida de desenvolvimento de software com cenários realistas, um aplicativo completo e um backlog compartilhado. Você trabalhará de forma iterativa para planejar alterações, criar código, testar o comportamento, revisar pull requests e gerenciar o trabalho com agentes.

## Cenário

Você é uma pessoa desenvolvedora recém-chegada à Tailspin Toys, uma empresa fictícia com temática de desenvolvimento de software que oferece financiamento coletivo para jogos de tabuleiro. O backlog da equipe já está registrado em issues do GitHub, prontas para você assumir. Ele inclui tarefas de recursos, como filtragem e paginação, e melhorias de qualidade, como acessibilidade e padrões de programação.

## Escolha seu ambiente

O GitHub Copilot acompanha você no ambiente em que trabalha. Escolha aquele que corresponde à forma como deseja desenvolver. Você pode usar a interface de linha de comando (CLI), o aplicativo para desktop, o agente de nuvem ou o Visual Studio Code. Cada workshop começa com a própria configuração e usa o cenário compartilhado do Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente baseado em agentes no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, o servidor Model Context Protocol (MCP) do Playwright, Agent Merge e comandos de barra úteis.

### [Aplicativo GitHub Copilot][app]

Execute sessões de agentes em paralelo, alterne modos de sessão, colabore em canvas e gerencie issues e pull requests do GitHub no aplicativo para desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, acompanhe o progresso e revise os pull requests abertos por ele.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
