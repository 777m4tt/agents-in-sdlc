Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software con escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres desarrollador en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo de software. El backlog del equipo ya está registrado como incidencias de GitHub y listo para que elijas una. Incluye funcionalidades como el filtrado y la paginación, además de mejoras de calidad como la accesibilidad y los estándares de código.

## Elige tu entorno

GitHub Copilot está disponible en el entorno donde trabajes. Elige el que mejor se adapte a tu forma de desarrollar. Cada taller tiene su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, el servidor Model Context Protocol (MCP) de Playwright, Agent Merge y comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agente en paralelo, cambia los modos de sesión, colabora en lienzos y gestiona incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [Agente de GitHub Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asíncrono, orienta su trabajo, supervisa el progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
